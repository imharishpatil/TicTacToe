
# Tic-Tac-Toe Game

A simple **Tic-Tac-Toe** game built using **HTML**, **CSS**, and **JavaScript**. This game allows two players to play against each other on the same device.



## Features
- Classic **Tic-Tac-Toe** gameplay (3x3 grid).
- Players can take turns to place X's and O's.
- The game detects a win or a draw and displays a corresponding message.
- Simple and interactive UI.

##  Technologies used
- **HTML**: Structure of the game board.
- **CSS**: Styling the game interface.
- **JavaScript**: Game logic and interactions.
## Gameplay Instructions

- The game board is a 3x3 grid where two players alternate placing X's and O's.
- The player who places three of their marks (X or O) in a horizontal, vertical, or diagonal row wins.
- If all 9 squares are filled and no one has won, the game ends in a draw.

## Game Controls
- Click any empty cell to place your mark (X or O).
- After a win or draw, you can click the "Restart" button to play a new game.
